# Layout and Shape

## Базовый ритм

Основной модуль — 4 pt. Большая часть композиции использует шаг 8 pt.

| Token | Value | Usage |
| --- | ---: | --- |
| `space1` | 4 | Микроинтервал |
| `space2` | 8 | Внутренний компактный интервал |
| `space3` | 12 | Связанные элементы |
| `space4` | 16 | Стандартный внутренний отступ |
| `space5` | 24 | Карточка и секция |
| `space6` | 32 | Крупный композиционный разрыв |
| `space7` | 48 | Разделение смысловых блоков |
| `space8` | 64 | Hero-интервал |

Не вводить локальные значения 10, 18, 22 или 28 pt без доказанной необходимости.

## Поля экрана

| Условие | Horizontal inset |
| --- | ---: |
| Компактная ширина до 375 pt | 20 pt |
| Стандартный iPhone | 24 pt |
| Ширина от 430 pt | 32 pt |

Максимальная ширина основного контента — 600 pt. Safe area всегда имеет приоритет над декоративным смещением.

## Радиусы

| Token | Value | Usage |
| --- | ---: | --- |
| `radiusSmall` | 8 | Badge и компактный control |
| `radiusMedium` | 14 | Вторичная поверхность |
| `radiusAction` | 18 | Кнопка и action card |
| `radiusCard` | 24 | Signature card |

Full pill не входит в базовый язык Card Impact. Он допускается только для системного маленького status badge, если прямоугольная форма ухудшает читаемость.

Круг является отдельной функциональной геометрией для icon-only controls, парной пошаговой навигации и двух равноценных исходов активного раунда. Он не заменяет `radiusAction` у остальных текстовых кнопок.

## Скошенный угол

- Малый компонент: 12 pt.
- Кнопка: 14 pt.
- Signature card: 18 pt.
- Hero card: максимум 24 pt.

Скошен только верхний правый угол. Повторение среза на всех четырёх углах запрещено.

## Обводки

- Signature card: 2 pt `ink900`.
- Secondary surface: 1 pt `ink900` с opacity 18%.
- Focus или selected: дополнительная внешняя рамка 3 pt соответствующего semantic color.
- Border не заменяет достаточный контраст поверхности.

## Flat shadows

Тени не имеют blur.

| Token | Offset | Usage |
| --- | --- | --- |
| `shadowSmall` | `0 × 3` | Badge и компактный control |
| `shadowAction` | `0 × 5` | Кнопка |
| `shadowCard` | `0 × 8` | Signature card |
| `shadowHero` | `0 × 12` | Редкий hero reveal |

Цвет тени — `ink900`. На тёмном фоне вместо невидимой тени используется контрастный offset layer.

Pressed-состояние:

- компонент смещается вниз на 3–4 pt;
- shadow offset сокращается до 1 pt;
- scale может уменьшиться до 0.985;
- fill не затемняется.

Для навигационной пары `Back / Forward` используется та же физика flat shadow: `Forward` — полный `shadowAction`, `Back` — offset 3 pt. Это сохраняет родство с Card Impact без ложного равенства действий.

## Адаптивность

- Используется адаптивный flow layout, а не абсолютное позиционирование всего экрана.
- Декоративный выход за сетку допускается только у одного hero-объекта.
- При недостатке вертикального пространства сначала сокращаются декоративные интервалы, затем перестраивается layout; текст не обрезается первым.
- Игровые действия переходят из горизонтального ряда в вертикальный при accessibility-размерах.
