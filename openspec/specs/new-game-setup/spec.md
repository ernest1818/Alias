# New Game Setup Specification

## Purpose

Определяет создание команд и формирование полной конфигурации перед запуском
новой игры.

## Requirements

### Requirement: Initial team set

Новая игра SHALL начинаться с двух различимых команд.

#### Scenario: Open team setup

- **GIVEN** пользователь начинает новую игру
- **WHEN** открывается экран команд
- **THEN** приложение SHALL показать ровно две команды
- **AND** каждая команда SHALL иметь собственную стабильную идентичность

### Requirement: Team count boundaries

Пользователь SHALL иметь возможность настроить от двух до пяти команд
включительно.

#### Scenario: Add teams up to the maximum

- **GIVEN** в игре меньше пяти команд
- **WHEN** пользователь добавляет команду
- **THEN** количество команд SHALL увеличиться на одну
- **AND** общее количество команд MUST NOT превышать пять

#### Scenario: Preserve the minimum team count

- **GIVEN** в игре две команды
- **WHEN** пользователь просматривает доступные действия
- **THEN** приложение MUST NOT позволять удалить одну из оставшихся команд

### Requirement: Distinct generated team names

Автоматически назначенные названия команд SHALL быть различимыми внутри одной
игры.

#### Scenario: Generate an additional team name

- **GIVEN** некоторые названия уже используются текущими командами
- **WHEN** приложение добавляет новую команду
- **THEN** оно SHALL выбрать название, отсутствующее среди текущих команд

### Requirement: Complete setup before category selection

Перед выбором категории приложение SHALL собрать команды и допустимые настройки
игры в одну согласованную конфигурацию.

#### Scenario: Continue from settings

- **GIVEN** создано допустимое количество команд
- **AND** настройки игры проходят проверку
- **WHEN** пользователь выбирает «Next»
- **THEN** приложение SHALL сохранить выбранные настройки
- **AND** SHALL открыть выбор категории для той же конфигурации игры

#### Scenario: Reject invalid challenge selection

- **GIVEN** режим заданий включён
- **AND** не выбрано ни одного задания
- **WHEN** пользователь пытается продолжить
- **THEN** приложение MUST NOT переходить к выбору категории
- **AND** SHALL сообщить, что необходимо выбрать хотя бы одно задание

### Requirement: Exactly one word category per new game

Перед подготовкой первого раунда пользователь SHALL выбрать одну категорию слов.

#### Scenario: Select a category

- **GIVEN** команды и настройки игры сформированы
- **WHEN** пользователь выбирает категорию слов
- **THEN** выбранная категория SHALL стать категорией текущей игры
- **AND** приложение SHALL открыть подготовку первого раунда
